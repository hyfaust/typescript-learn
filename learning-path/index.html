    学习路径概述¶

    本学习路径通过一系列精心设计的项目，帮助你从 TypeScript 入门到精通。所有项目都使用 Deno 作为运行时环境。

    学习路径结构¶

    阶段一：基础入门¶

    目标：掌握 TypeScript 基础语法和 Deno 环境

    1. 项目1：基础入门
    2. TypeScript 和 Deno 简介
    3. 基本类型：string, number, boolean, array, tuple, enum
    4. 变量声明：let, const

    5. 函数：函数类型，可选参数，默认参数

    6. 项目2：接口和类型

    7. 接口定义：属性，方法，索引签名
    8. 类型别名：type 关键字
    9. 可选属性和只读属性

    10. 函数类型接口

    11. 项目3：类和面向对象

    12. 类定义：属性，方法，构造函数
    13. 继承：extends，super
    14. 访问修饰符：public，private，protected
    15. 抽象类：abstract

    阶段二：进阶特性¶

    目标：掌握 TypeScript 高级类型和模块系统

    1. 项目4：泛型编程
    2. 泛型函数
    3. 泛型接口
    4. 泛型类

    5. 泛型约束（extends）

    6. 项目5：高级类型

    7. 联合类型（Union Types）
    8. 交叉类型（Intersection Types）
    9. 类型守卫（Type Guards）

    10. 可辨识联合（Discriminated Unions）

    11. 项目6：模块和命名空间

    12. ES 模块系统
    13. 导入导出语法
    14. 模块解析策略
    15. 命名空间（Namespaces）

    阶段三：高级特性¶

    目标：掌握 TypeScript 异步编程和高级特性

    1. 项目7：异步编程
    2. Promise 基础
    3. async/await 语法
    4. 异步迭代器（Async Iterators）

    5. 生成器（Generators）

    6. 项目8：错误处理和测试

    7. 自定义错误类
    8. Deno 测试框架
    9. 断言库

    10. 测试覆盖率

    11. 项目9：装饰器和元数据

    12. 装饰器概念
    13. 类装饰器
    14. 方法装饰器
    15. 元数据反射

    阶段四：实战项目¶

    目标：通过实战项目巩固所学知识

    本地应用¶

    1. 项目10：CLI 工具

      • 参数解析
      • 用户交互
      • 输出格式化
      • 实战：文件搜索工具

    2. 项目11：文件处理工具

      • 文件系统 API
      • 流处理
      • 数据转换
      • 实战：日志分析工具

    Web 应用¶

    1. 项目12：Web 应用
      • Web 框架：Oak, Hono
      • 路由系统
      • 中间件
      • 实战：博客系统

    学习建议¶

    1. 循序渐进¶

    按照项目顺序学习，每个项目都建立在前一个项目的基础上。

    2. 动手实践¶

    运行每个示例代码，尝试修改代码，观察变化。

    3. 完成练习¶

    每个项目都有练习题，完成它们以加深理解。

    4. 查阅文档¶

    遇到问题时查阅 Deno 和 TypeScript 官方文档。

    5. 构建项目¶

    尝试构建自己的项目，应用所学知识。

    环境准备¶

    安装 Deno¶

    # Windows (PowerShell)
iwr https://deno.land/install.ps1 -useb | iex

# macOS/Linux
curl -fsSL https://deno.land/install.sh | sh

    验证安装¶

    deno --version

    配置 IDE¶

    推荐使用 VS Code，安装以下扩展： - TypeScript Vue Plugin (Volar) - ESLint - Prettier

    学习时间表¶

    建议的学习时间表（可根据个人情况调整）：

    第一周：基础入门¶

    • 项目1-3：每天1个项目
    • 总时间：约6-8小时

    第二周：进阶特性¶

    • 项目4-6：每天1个项目
    • 总时间：约6-8小时

    第三周：高级特性¶

    • 项目7-9：每天1个项目
    • 总时间：约6-8小时

    第四周：实战项目¶

    • 项目10-12：每天1个项目
    • 总时间：约8-10小时

    评估标准¶

    完成学习路径后，你应该能够：

    1. 理解 TypeScript 类型系统
    2. 使用基本类型和高级类型
    3. 设计接口和类型别名

    4. 应用泛型编程

    5. 掌握 TypeScript 高级特性

    6. 使用装饰器和元数据
    7. 实现异步编程

    8. 进行错误处理和测试

    9. 构建实际应用

    10. 开发 CLI 工具
    11. 处理文件系统操作

    12. 构建 Web 应用

    13. 理解 TypeScript 与 JavaScript 的区别

    14. 知道何时使用 TypeScript
    15. 理解类型安全的重要性
    16. 掌握 TypeScript 开发工具链

    常见问题¶

    Q: 我需要 JavaScript 基础吗？¶

    A: 是的，建议有 JavaScript 基础。如果没有，可以先学习 JavaScript 基础。

    Q: 我需要安装 Node.js 吗？¶

    A: 不需要，我们使用 Deno 作为运行时。

    Q: 学习路径需要多长时间？¶

    A: 建议4周，但可以根据个人情况调整。

    Q: 我可以跳过某些项目吗？¶

    A: 不建议，每个项目都建立在前一个项目的基础上。

    Q: 学习路径是免费的吗？¶

    A: 是的，所有内容都是开源的。
