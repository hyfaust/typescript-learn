## Introduction

This project provides a structured learning path for mastering TypeScript through hands-on projects. Each project is designed to teach specific TypeScript concepts while building practical applications using Deno as the runtime environment.

### Why TypeScript?

TypeScript is a superset of JavaScript that adds static type checking and advanced features:

- **Static Type System** — Catch errors at compile time, not runtime
- **Better IDE Support** — Auto-completion, refactoring, and navigation
- **Code Maintainability** — Types serve as documentation
- **Gradual Adoption** — Can be incrementally added to existing JavaScript projects

### Why Deno?

Deno is a modern JavaScript/TypeScript runtime with built-in security and tooling:

- **Native TypeScript Support** — No compilation step required
- **Secure by Default** — Explicit permissions model
- **Modern Toolchain** — Built-in test runner, formatter, and linter
- **Web Standards** — Uses Web Standard APIs
- **URL-based Imports** — No node_modules required

## Learning Stages

### Stage 1: Fundamentals

**Projects 1-3** cover the core TypeScript basics:

- **01-basics** — Learn about TypeScript's type system, variable declarations, and function definitions
- **02-interfaces** — Master interface design, type aliases, and object structure contracts
- **03-classes** — Understand object-oriented programming with TypeScript classes

### Stage 2: Intermediate

**Projects 4-6** introduce TypeScript's powerful features:

- **04-generics** — Create reusable, type-safe components with generics
- **05-advanced-types** — Work with union types, intersection types, and type guards
- **06-modules** — Organize code with ES modules and namespaces

### Stage 3: Advanced

**Projects 7-9** cover advanced TypeScript patterns:

- **07-async** — Master asynchronous programming with Promises and async/await
- **08-error-testing** — Implement proper error handling and write tests
- **09-decorators** — Use decorators for metaprogramming

### Stage 4: Real-World Projects

**Projects 10-12** apply knowledge to practical applications:

- **10-cli-tool** — Build a command-line tool with argument parsing
- **11-file-processing** — Process files with streams and transformations
- **12-web-app** — Create a web server with routing and middleware
